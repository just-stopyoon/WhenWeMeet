# 언제 만날래 — 모바일 React 프로토타입

친구들의 가능한 날짜·점심/저녁을 모으고, 지역을 투표한 뒤 음식점·카페 링크를 저장하는 인터랙티브 프로토타입입니다.

## 실행

Node.js 22.13 이상이 설치된 환경:

```sh
npm install
npm run dev
```

기본 주소: http://localhost:3000

이 PC에서는 `start-local.ps1`로도 실행할 수 있습니다. 실행 중인 서버가 있으면 기존 주소를 사용하세요.

## 체험 순서

1. 첫 화면의 `오랜만에 우리 다섯` 샘플 모임을 엽니다.
2. 달력 날짜를 누른 뒤 점심 또는 저녁을 선택하고 제출합니다.
3. 이메일 창을 건너뛰거나 샘플 주소를 입력합니다. 실제 이메일은 발송하지 않습니다.
4. 화면 아래 `친구들 응답 채우기`를 누르면 다른 샘플 참여자 응답이 완료됩니다.
5. 날짜·시간대를 확정하고 지역을 1~2개 선택해 제출합니다.
6. 다시 `친구들 응답 채우기`를 누르면 집계가 끝납니다. 동률이면 재투표/추첨을 체험합니다.
7. 최종 화면에서 음식점·카페 링크를 등록하고 공유 내용을 복사할 수 있습니다.
8. 홈 오른쪽 계정 버튼에서 샘플을 초기화하거나 다른 닉네임으로 전환합니다.

새 계정으로 2명 방을 만들고 계정을 전환해 같은 브라우저에서 투표하는 흐름도 가능합니다. 초대 코드는 방 관리에서 확인합니다.

## 구현 범위

- React 19 + TypeScript, Vite/Vinext 기반 로컬 프로젝트
- 기본 너비 430px, 360px 모바일 대응, 하단 고정 버튼·네이티브 dialog 바텀시트
- 계정·여러 모임·고정 정원·기간 검증·달력 제출·날짜 후보·참석 재확인
- 지역 추가 마감·투표·동률 재투표·추첨·최종 링크 보드
- 방장 위임·강퇴·나가기·종료·만료 조회 제한
- 브라우저 localStorage로 체험 상태 유지

## 실제 서비스와의 차이

실제 서버와 DB, 기기 간 동기화, 이메일 발송, 네이버 정보 자동 완성은 연결하지 않았습니다. 저장된 계정/PIN 해시는 **프로토타입용**이며 실제 인증 보안으로 사용할 수 없습니다. 실제 개인정보를 입력하지 마세요. 서버 권한 검사, 비밀번호 KDF·시도 제한·세션 보호, 자동 삭제 작업은 운영 구현이 필요합니다.

현재 미정 정책의 체험 가정:
- 집계 이후 방장이 최종 날짜·시간대를 확인합니다.
- 후보 외 날짜 참석 재확인은 현재 활성 멤버 전원 기준입니다.
- 방장은 넘기기 또는 종료 후 나갈 수 있습니다.
- 지역 확정 뒤 날짜/지역 변경 UI는 제공하지 않습니다.
- 링크 이름은 직접 입력합니다. 자동 미리보기는 연결 전입니다.

## 코드 위치

- `app/page.tsx`: 화면·체험 상태 및 인터랙션
- `app/globals.css`: 디자인 토큰과 모바일 스타일
- `lib/meeting.ts`: 데이터 모델·날짜/지역 집계
- `app/layout.tsx`: 한국어 문서·메타데이터

## 검증

```sh
npx tsc --noEmit

npm run build
```

실행 확인은 HTTP 응답 및 컴파일 기준으로 수행했습니다. 실제 브라우저 조작·시각 검증은 별도 수행하지 않았습니다. 설치 패키지의 보안 경고는 배포 전 검토가 필요하며 현재는 로컬 프로토타입입니다.
