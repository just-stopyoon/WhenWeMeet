# Web Push VAPID 비공개 키를 D1에 보관한다

Web Push 발송에 쓰는 VAPID 키 쌍은 서버가 처음 필요할 때 한 번 만들어 D1 테이블에 저장하고, 이후 그 키를 계속 쓴다. 원본 앱의 배포(Sites)는 `.openai/hosting.json`의 D1·R2 바인딩과 `drizzle/` 마이그레이션만 배포물에 넣고, 비밀 값(secret)을 넣는 수단은 확인하지 못했다. 코드나 저장소에 키를 두는 방법은 쓰지 않는다. 그래서 배포 설정 없이 동작하고 테스트용 임시 D1에서도 그대로 도는 D1 보관을 골랐다(2026-11-21 알림 회의 Q10).

## Consequences

- D1에 접근할 수 있는 사람은 이 앱 이름으로 알림을 보낼 수 있다. D1에는 이미 계정·세션·모임이 모두 있어 접근 권한의 범위는 넓어지지 않는다고 판단했다.
- 키 행이 지워지거나 바뀌면 기존 구독이 모두 무효가 되어, 사용자가 기기마다 알림을 다시 켜야 한다. 키를 다른 보관 방식(예: 배포 비밀 값)으로 옮길 때도 같은 키를 옮겨야 구독이 유지된다.
- 키는 로그·분석에 남기지 않는다(PIN·쿠키·토큰과 같은 취급).

## Considered Options

- 배포 비밀 값(Sites 환경 변수): 지원 여부를 확인하지 못해 보류했다.
- 코드·저장소에 키를 두기: 공개 저장소라 쓰지 않는다.
